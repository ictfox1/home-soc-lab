# Этап 3. Cоздание ВМ soc-wazuh и установка Ubuntu Server 22.04

## Задача
Развернуть первую ВМ - будущий SIEM-сервер.

## Параметры ВМ

| Параметр 		| Значение 		|
|---------------|---------------|
| RAM	        | 4 GB 	        |
| CPU 	        | 2 vCPU 	    |
| Диск 	        | 40 GB 	    |
| Adapter 1     | NAT	        |
| Adapter 2 	| Internal Network (soclab)	|
| IP (internal)	| 10.10.10.10 	|
| user	        | socadmin 	    |

## Сетевая настройка
Настройка сети выполнятеся через netplan, путём редfктирования 00-installer-config.yaml - настроек сети, применяющихся при загрузке системы. Расположение `/etc/netplan/00-installer-config.yaml`:

```yaml
network:
  version: 2
  ethernets:
    enp0s3:
      dhcp4: true
    enp0s8:
      dhcp4: false
      addresses:
        - 10.10.10.10/24
```

## Настройка SSH, проброс портов
Чтобы была возможность подключиться к ВМ с хоста при помощи команды `VBoxManage controlvm "soc-wazuh" natpf1 "ssh,tcp,,2222,,22"` добавляем правила для проброса портов. Таким образом хост будет иницилизировать соединение по адресу 127.0.0.1 на динамическом порту с портом 2222 VirtualBox, после чего гипервизор пробросит соединение внутрь ВМ на 22 порт.
