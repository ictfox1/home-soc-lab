# Этап 5. Установка wazuh на soc-wazuh

## Задача
Установить wazuh на `soc-wazuh`, пробросить порты для доступа к дашборду и установить агента на soc-ubuntu-web.

## Параметры Wazuh
| Параметр | Значение |
| :--- | :--- |
| Режим установки | All-in-One (Indexer + Server + Dashboard) |
| IP-адрес (internal) | `10.10.10.10` |
| Порт веб-интерфейса | `443` (проброшен на `8443` хоста) |
| Агенты | `soc-ubuntu-web` (10.10.10.40) |

## Действия

1. При помощи команды `curl -sO https://packages.wazuh.com/4.7/wazuh-install.sh` скачиваем скрипт для установки и запускаем саму уcтановку.
2. Пробрасываем порт для браузера `./VBoxManage controlvm "soc-wazuh" natpf1 "wazuh-dash,tcp,,8443,,443"`.
3. В барузере в wazuh добавляем агента soc-ubuntu-web и запуcкаем его после установки.


## Результат 

- Wazuh SIEM успешно развернут на soc-wazuh.
- Веб-интерфейс доступен и работает.
- Агент soc-ubuntu-web успешно подключен и находится в статусе Active.
