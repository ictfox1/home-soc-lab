# Этап 9. Развёртывание Windows 10 и ввод в домен

## Задача
Развернуть рабочую станцию `soc-win10`, имитирующую компьютер сотрудника, и ввести её в домен `soclab.local`.

## Параметры ВМ
| Параметр | Значение |
| :--- | :--- |
| Имя ВМ | `soc-win10` |
| IP (internal) | `10.10.10.60/24` |
| DNS | `10.10.10.50` (Контроллер домена) |
| ОС | Windows 10 Enterprise Evaluation |

## Действия
1. Установлен Windows 10.
2. Настроен статический IP `10.10.10.60` и DNS `10.10.10.50`.
3. Проверена связь с доменом (`ping soclab.local`).
4. Компьютер успешно введен в домен `soclab.local`.
5. Установлен и запущен Wazuh Agent для Windows.
6. Установлен Sysmon с конфигурацией SwiftOnSecurity и настроена отправка логов в Wazuh.

## Результат
- Рабочая станция `soc-win10` является частью домена.
- Агент Wazuh успешно подключен к SIEM.
