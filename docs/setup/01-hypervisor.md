# Этап 2. Установка и настройка гипервизора

## Задача
Подготовить VirtualBox для хостинга 6 виртуальных машин лаборатории.

## Действия

### 2.1. Проверка установки
- Версия VirtualBox: `7.0.20`

### 2.2. Ресурсы хоста
- CPU: AMD Ryzen 7 7445HS (8 ядер / 16 потоков)
- RAM: 32 GB
- Диск: 512 GB SSD (из них ~150 GB выделено под ВМ)

### 2.3. Планирование сети

**Типы сетей VirtualBox:**
- NAT — для обновлений и управления
- Internal Network `soclab` — изолированная LAN

**Объяснение выбора**
- Host-only даёт доступ хосту к ВМ, но ВМ друг друга могут видеть только через хост. Нам же нужно, чтобы ВМ общались напрямую
- В Bridged — уязвимые ВМ окажутся в одной сети с другими устройствами, что может привести к их компрометации

**Схема адресации:**

| ВМ 		    | IP 		    | Роль 		|
|---------------|---------------|-----------|
| soc-wazuh 	| 10.10.10.10 	| SIEM		|
| soc-suricata 	| 10.10.10.20 	| IDS 		|
| soc-kali 	    | 10.10.10.30 	| Атакующий |
| soc-ubuntu-web| 10.10.10.40 	| Жертва 	|
| soc-dc 	    |10.10.10.50 	| Domain    |
| soc-win10 	| 10.10.10.60 	| Клиент 	|

### 2.4. Хранение
- Default Machine Folder: `D:\projects\VMs`
- ISO-образы: `D:\projects\VMs\_iso`

## Результат
VirtualBox готов. Сеть `soclab` будет создана при настройке первой ВМ.

## Выводы
- Использую два адаптера на ВМ: NAT + Internal Network
- Internal Network предпочтительнее Host-only для имитации реальной LAN
