# Этап 11. Интеграция логов UFW с Wazuh и настройка корреляции

## Задача
Настроить сбор логов межсетевого экрана UFW (Host-based firewall) в Wazuh SIEM, а также реализовать правила корреляции для снижения шума (Alert Fatigue).

## Действия

1. На сервере `soc-ubuntu-web` включен UFW и логирование (`ufw logging on`).
2. В конфигурацию агента Wazuh добавлен `<localfile>` для чтения `/var/log/ufw.log` (формат `syslog`).
3. На менеджере Wazuh (`soc-wazuh`) создан кастомный декодер `my_ufw` (`local_decoder.xml`) для извлечения IP-адресов источника, назначения и портов из строк лога UFW.
4. Созданы правила корреляции в `local_rules.xml`:
   - `104101` (Level 3): Базовое правило для фиксации одиночных блокировок.
   - `104151` (Level 10): Композитное правило, которое срабатывает при множественных блокировках с одного IP-адреса за короткий промежуток времени (детект порт-сканирования).

## Результат
- Wazuh успешно распознает логи UFW.
- В дашборде появляются высокоуровневые алерты (`104151`) при попытке сетевого сканирования.
- Настроен механизм защиты от ложных срабатываний (шума).
