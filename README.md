**# Home SOC Lab**



**Домашняя лаборатория для отработки навыков мониторинга, детектирования и реагирования на инциденты информационной безопасности.**



**## 🎯 Цель проекта**



**Построить изолированный стенд, имитирующий корпоративную сеть, и отработать полный цикл работы SOC-аналитика:**

**\*\*атака → детект → расследование → документирование → рекомендации\*\*.**

**## 🧰 Используемый стек**



**| Компонент | Технология | Назначение |**

**|-----------|-----------|------------|**

**| Гипервизор | VirtualBox | Хостинг виртуальных машин |**

**| SIEM | Wazuh | Сбор логов, корреляция, алертинг |**

**| IDS/IPS | Suricata | Анализ сетевого трафика |**

**| Атакующий | Kali Linux | Симуляция атак |**

**| Целевые ОС | Ubuntu Server, Windows Server (AD), Windows 10 | Имитация инфраструктуры |**

**| Уязвимое приложение | DVWA | Тренировка веб-атак |**

**## 📁 Структура репозитория**



**- `docs/` — документация по этапам: архитектура, настройка, атаки, отчёты об инцидентах**

**- `configs/` — конфигурационные файлы (Wazuh, Suricata, VirtualBox)**

**- `scripts/` — скрипты автоматизации**

**- `diagrams/` — схемы сети и архитектуры**

**- `screenshots/` — скриншоты дашбордов и результатов**
